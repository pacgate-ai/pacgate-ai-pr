## 4. 聊天管线 E2E (deer-flow agent 全流程)

Run `3e36fb28` (thread `780ac8e0`):

| 阶段 | 耗时 | tokens (in/out/cached) |
|---|---|---|
| run 创建 → worker 启动 | 1s | - |
| Turn 1 (首次 LLM 调用) | **137.1s** | 48807 / 257 / 0 |
| 工具调用 (vaquill x22) | ~25s | - |
| Turn 2 | 10.0s | 49779 / 52 / 48807 |
| Turn 3 (最终回复) | 35.4s | 51202 / 711 / 49776 |
| **端到端总计** | **197.5s** | 3 turns, 9 values 事件 |

关键发现:
- 首 turn 137s 的根因是 48k-token 系统提示词 + 137 个 MCP 工具定义, 全部未缓存。这是 agent 行为, 不是缺陷。
- Prompt cache 生效: turn 2/3 cached_tokens = 48807/49776, 后续 turn 延迟从 137s 降到 10-35s。
- 模型未服从 指令 (调用了 vaquill 22 次) — agent 自主性。
- SSE 流完整: metadata → 9x values → end, 451KB, 无中断。
