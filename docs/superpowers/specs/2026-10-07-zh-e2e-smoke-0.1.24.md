## 1. 编码 问题 根因 (已证实)

**受损 范围: 仅限 本机 PS 5.1 生成 的 .md 报告 文件 (v1 基准 报告 + v1 审计 报告)**

证据:
- 报告 字节 为 有效 UTF-8 (无 BOM), 但 内容 是 mojibake: UTF-8 解码 得 鍏迟 类 乱码, GBK 解码 得 閸泣 类 二次 乱码
- 生成 脚本 bench-report-1007c.ps1: 无 BOM, 源 码 中 全栅 (U+5168 U+6805) 完好
- **根因**: PS 5.1 按 系统 代码页 (GBK) 读 无 BOM 的 .ps1 源 码 → 字符串 字面量 在 内存 中 已经 乱码 → WriteAllText 再 编码 为 UTF-8 = 双重编码
- **修复**: 报告 内容 改 为 用 Unicode 码点 构建 (免疫), 写 入 UTF-8 BOM
