# Sync to 0.2.35 and prove the full stack end to end Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move this machine from a mixed 0.2.32-running / 0.2.34-pinned stack onto the published 0.2.35 release, re-open the 397 chunks the old redactor verdict refused, and prove every lane (deer-flow, qm, OpenViking, document generation, OCR, sanitizer, legal journey) round-trips - without losing a byte of local data.

**Architecture:** The merge is a **no-op by construction**. `git merge-tree` predicts zero conflicts and the merge result tree is byte-identical to `upstream/main`'s tree, so every local commit's content is already upstream. The work is therefore not conflict resolution - it is (a) getting the checkout onto a branch the installer can fast-forward, (b) re-staging the qm runtime copy so two live qm defects are fixed, (c) recreating five containers onto 0.2.35, and (d) re-sanitizing the documents whose stored verdicts predate the fix. Data safety comes from the fact that every runtime path is gitignored by upstream's own `.gitignore`, verified in a throwaway repo before touching anything.

**Tech Stack:** git, Docker Compose (`deploy/client-bundle/compose.prod.yaml`, `deploy/qm-pacgate/compose.qm.yaml`), PowerShell 7.7, `psql`/`pg_dump` inside `pacgate-db` and `qm-pacgate-pg`, Python 3.12 inside `deer-flow`, the pacgate-api HTTP surface, Ollama.

**Spec:** `docs/superpowers/plans/2026-11-14-cut-0.2.35-to-close-the-release-gap.md` (the release this plan consumes) and `deploy/HANDOFF-SYNC-TO-ORIGIN-MAIN.md` (the vendor's own delta instructions for 0.2.35).

## Global Constraints

- **Never `git reset --hard`, `git checkout --`, or auto-stash.** This repository's own records state that a hard reset destroyed a fix on 2026-11-01. It is a live install with unpushed work.
- **Never move a published tag.** `v0.2.35` peels to `2924798cb44a` and stays there.
- **Never suppress a gate to go green.** No allowlist, no `-AllowUnreleased`, no skip. Exit 2 is CANNOT CHECK, never a pass.
- **PowerShell 5.1 must not run `install.ps1`.** Native stderr becomes a terminating error under `$ErrorActionPreference = 'Stop'`. Use `pwsh` (7.7.0 on this box).
- **Do not generate `deer-flow-config.local.yaml`.** `nemotron-3.5-bolt:74b-a9b-iq2` is not installed here, so the 74B override would point the picker default at a missing tag. The tracked config stays authoritative.
- **Do not add the 74B to `ollama-models.txt`.** It is OVER_CAP for the 16 GB client class (`docs/superpowers/decisions/2026-11-08-local-model-posture.md`).
- **Cloud chat models are intentional.** `deepseek-v4.1-flash:cloud` for MAIN is the recorded 2026-08-30 decision. Do not re-flag it as a residency bug.
- **No em-dashes in visible copy.** Use hyphens.
- **Every claim in the outcome record needs a fresh command in the same message.** The 0.2.34 handoff carried four stale measurements; that is the defect this rule exists for.

### The two facts that decide the shape of this plan

1. **There is nothing to merge.** The merge result tree equals upstream's tree exactly. Any "merge and resolve conflicts" step would be theatre. The correct move is a **fast-forward of `main`**, which also puts the checkout on a branch `origin` actually has - the precondition `install.ps1 -Update` needs and the reason plan 032 was blocked.
2. **0.2.35 is inert until the verdicts are recomputed.** The verdict is computed at sanitize time and stored. Pulling the image replaces the code that computes it; it does not recompute rows already written. A machine can run 0.2.35 with a fully green stack and still have 397 blocked chunks.

$exclude = @('.env','node_modules','.generated')
Get-ChildItem -LiteralPath $src -Recurse -File -Force | Where-Object {
    $rel = $_.FullName.Substring((Resolve-Path $src).Path.Length).TrimStart('\','/')
    $top = ($rel -split '[\\/]')[0]

    $rel = $_.FullName.Substring((Resolve-Path $src).Path.Length).TrimStart('\','/')

- [ ] **Step 2: Align `PUBLIC_API_URL` with `QM_PUBLIC_URL`**

The portal's cross-origin guard compares the request `Origin` against the single origin derived from `QM_PUBLIC_URL`. `PUBLIC_API_URL` naming a different host makes every proxied POST a cross-origin call, which the UI surfaces as an LLM error rather than an address problem.

```powershell
$envPath = 'deploy/client-bundle/qm-pacgate/.env'
$raw = [System.IO.File]::ReadAllText($envPath)
$m = [regex]::Match($raw, '(?m)^\s*QM_PUBLIC_URL\s*=\s*(\S+)')
$publicUrl = $m.Groups[1].Value.Trim().TrimEnd('/')
$hostName = ([Uri]$publicUrl).Host
$corePort = '8180'
$newApi = "http://${hostName}:${corePort}"
$raw = [regex]::Replace($raw, '(?m)^\s*PUBLIC_API_URL\s*=.*$', "PUBLIC_API_URL=$newApi")
[System.IO.File]::WriteAllText($envPath, $raw, (New-Object System.Text.UTF8Encoding($false)))
Select-String -Path $envPath -Pattern '^(QM_PUBLIC_URL|PUBLIC_API_URL)=' | ForEach-Object { $_.Line }
```

Expected: `QM_PUBLIC_URL=http://pacgate-ai02:8181` and `PUBLIC_API_URL=http://pacgate-ai02:8180`. The **host** matches; the **port** stays 8180 because reusing 8181 would point the API calls at the portal itself.

`compose pull` reports "Pulled" even when the local tag does not move. Compare image IDs before and after.

`docker compose images --format '{{.ID}}'` is **not** usable here: compose's `images` subcommand rejects the Go template (`format value "{{.ID}}" could not be parsed: parsing failed`, exit 1). Read the local tag from `docker images` instead.

Note the `${repo}` braces in the regex. `"^ghcr\.io/jzkk720/$repo:0\.2\.35 "` is **not** a parse error but is silently wrong: PowerShell reads `$repo:` as a scope qualifier, interpolates nothing, and the pattern becomes `^ghcr\.io/jzkk720/\.2\.35 `, which matches no image. The helper then reports `<absent>` for every repo even after a successful pull. This was measured on 7.7.0.

```powershell

  $line = docker images --format '{{.Repository}}:{{.Tag}} {{.ID}}' |
    Where-Object { $_ -match "^ghcr\.io/jzkk720/${repo}:0\.2\.35 " }
  if ($line) { ($line -split '\s+')[-1] } else { '<absent>' }
}
$before = @{}

docker compose -f compose.prod.yaml pull
"pull exit=$LASTEXITCODE"

Pop-Location
```
