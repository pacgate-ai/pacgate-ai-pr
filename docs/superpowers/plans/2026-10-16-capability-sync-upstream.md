# Capability Sync to Upstream — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the 5 verified capability gaps between AIPC #1's v0.1.31 stack and upstream `JZKK720/pacgate-ai-pr`, so a fresh machine gets all 30 MCP connectors and all 60 skills from `docker compose pull` alone.

**Architecture:** Two mechanisms. (1) The MCP connector template expands from 3 to 30 servers with `${VAR}` placeholders, and `install.ps1` gains a generic substitution pass so every connector key comes from `.env`. (2) The skills tree is baked into the `deer-flow-pacgate` image by CI, and the mono-folder-only compose mount is demoted to a commented dev override.

**Tech Stack:** PowerShell 5.1 (`install.ps1`), Docker/BuildKit, GitHub Actions, JSON, YAML.

## Global Constraints

- **Target release:** `v0.1.32` (current live: `0.1.31`).
- **Image namespace:** `ghcr.io/jzkk720/*` — pinned by `GHCR_NAMESPACE` in `build-ghcr.yml`. Never `pacgate-ai/*`.
- **Repo layout:** git root is `pacgate-law/`. Upstream root `F` maps to local `pacgate-ai/F`; upstream `pacgate-ai/G` maps to local `pacgate-ai/pacgate-ai/G`.
- **Push target:** `fork` = `pacgate-ai/pacgate-ai-pr` (we can push). `upstream` = `JZKK720/pacgate-ai-pr` (**we cannot push** — PAT has `push=False`).
- **Encoding:** never use `Get-Content`/`Set-Content` on UTF-8 files with CJK. Use `[System.IO.File]::ReadAllText/WriteAllText` with `UTF8Encoding($false)` (no BOM). The template carries 314 CJK characters.
- **PS 5.1 traps:** `??` unsupported; `$pass` collides case-insensitively with `$script:pass`; `docker inspect -f '{{index ...}}'` breaks — use `ConvertFrom-Json`.
- **Credential gate:** the 3 leaked blobs (`5855e649`, `8e18bfce`, `a59e30ed`) must never appear in a pushed tree. Verify by blob SHA, not filename (CJK paths are octal-escaped).
- **Never** commit `.env`, `deer-flow-extensions-config.json`, or `data/` — all gitignored.
- **Per-machine values stay local:** `PACGATE_MODEL_{MAIN,MID,LOW}`, `GATEWAY_CORS_ORIGINS`, model roster (user directive 2026-09-21).

- [ ] **Step 1: Replace the single-key substitution with a generic pass**

In `pacgate-ai/deploy/client-bundle/install.ps1`, find this exact line (L434):

```powershell
            $df = (Get-Content $dfTemplate -Raw -Encoding UTF8).Replace('${OPENVIKING_ROOT_API_KEY}', $dfKey)
```

Replace it with:

```powershell
            # Generic placeholder pass: substitute EVERY ${VAR} the template
            # declares, from .env. Previously only OPENVIKING_ROOT_API_KEY was
            # replaced, so the 27 legal-database connectors could not be
            # templated at all - they lived only in the rendered (gitignored)
            # file, and a fresh machine got 3 servers instead of 30.
            #
            # .Replace() is a LITERAL string replace, so a value containing '$'
            # is safe (unlike -replace, which would treat it as a regex).
            $df = Get-Content $dfTemplate -Raw -Encoding UTF8
            foreach ($k in $envVars.Keys) {
                $df = $df.Replace('${' + $k + '}', [string]$envVars[$k])
            }

            # Report any placeholder left unsubstituted. NOT fatal: a missing
            # connector key must degrade to "fewer sources", never fail the
            # install. OPENVIKING_ROOT_API_KEY is guarded above and cannot
            # reach here unset.
            $leftover = [regex]::Matches($df, '\$\{[A-Z_]+\}') |
                ForEach-Object { $_.Value } | Sort-Object -Unique
            if ($leftover.Count -gt 0) {
                Write-Host "[WARN] Unsubstituted placeholders in $dfRendered - these connectors will be skipped:" -ForegroundColor Yellow
                Write-Host "       $($leftover -join ', ')" -ForegroundColor Yellow
                Write-Host "       Set them in .env to enable the corresponding connectors." -ForegroundColor Yellow
            }
```

```powershell
$ErrorActionPreference = "Stop"
$root = "c:\Users\pacga\github-pr\pacgate-law"
$rel  = "pacgate-ai/deploy/client-bundle/patches/deer-flow-uploads-middleware.py"
$upRel = "deploy/client-bundle/patches/deer-flow-uploads-middleware.py"

# PAT from Windows Credential Manager (never printed)
$psi = New-Object System.Diagnostics.ProcessStartInfo
$psi.FileName = "git"; $psi.Arguments = "credential fill"
$psi.RedirectStandardInput = $true; $psi.RedirectStandardOutput = $true
$psi.UseShellExecute = $false
$p = [System.Diagnostics.Process]::Start($psi)
$p.StandardInput.WriteLine("protocol=https"); $p.StandardInput.WriteLine("host=github.com")
$p.StandardInput.WriteLine(""); $p.StandardInput.Close()
$out = $p.StandardOutput.ReadToEnd(); $p.WaitForExit()
$pat = $null
foreach ($l in ($out -split "`n")) { if ($l -match '^password=(.+)$') { $pat = $Matches[1].Trim() } }
if (-not $pat) { throw "no PAT" }

# LF-normalize: the worktree is CRLF, upstream is LF. Without this the diff
# becomes whole-file noise.
$text = [System.IO.File]::ReadAllText((Join-Path $root $rel), [System.Text.Encoding]::UTF8)
$text = $text -replace "`r`n", "`n"
$b64  = [Convert]::ToBase64String([System.Text.Encoding]::UTF8.GetBytes($text))

$h = @{ Authorization = "Bearer $pat"; Accept = "application/vnd.github+json"; "User-Agent" = "pacgate-push" }
$uri = "https://api.github.com/repos/pacgate-ai/pacgate-ai-pr/contents/$upRel"

# Need the existing blob SHA if the file already exists (update vs create)
$sha = $null
try {
  $cur = Invoke-RestMethod -Uri "$uri`?ref=main" -Headers $h -Method Get
  $sha = $cur.sha
  Write-Output "existing file, sha=$sha"
} catch { Write-Output "new file" }

$body = @{
  message = "fix(patches): add deer-flow-uploads-middleware.py

Mounted in compose.bundle.yaml but absent from upstream patches/ (17 vs 18),
so a fresh deploy would mount a non-existent file and the uploads middleware
override would silently not apply."
  content = $b64
  branch  = "main"
}
if ($sha) { $body.sha = $sha }

$json = $body | ConvertTo-Json -Depth 5
$bytes = [System.Text.Encoding]::UTF8.GetBytes($json)
$resp = Invoke-RestMethod -Uri $uri -Headers $h -Method Put -Body $bytes -ContentType "application/json; charset=utf-8"
Write-Output ("pushed: " + $resp.commit.sha)
```
