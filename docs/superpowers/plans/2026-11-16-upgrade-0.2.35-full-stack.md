# PacGate-AI Full-Stack Upgrade 0.2.34 → 0.2.35 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adopt `v0.2.35` (`2924798`) into the `pacgate-ai/` subtree, preserve every local delta that upstream still lacks, pin the live stack to the `0.2.35` GHCR images, re-sanitize the documents the old verdict rule blocked, and prove deer-flow / qm / openviking / document-generation / OCR / sanitizer / full-legal-journey all round-trip — with zero loss of the 276 documents, 5,599 chunks, 65 matters and 2,001 audit rows currently in the database.

**Architecture:** The two git histories are **unrelated** (different root commits), so no `git merge` is possible. Adoption is an **index swap** (`git read-tree --prefix=pacgate-ai/ "v0.2.35^{tree}"`) followed by re-applying the local deltas the swap reverts. Upstream root maps to the local `pacgate-ai/` subtree: upstream `deploy/x` → local `pacgate-ai/deploy/x`.

**Tech Stack:** PowerShell 5.1 (Windows), Docker Compose v2, GHCR (`ghcr.io/jzkk720/*`), Rust 1.94 (`rust:1.94-bookworm`), Postgres 16 + pgvector, Ollama, Python 3.12 patches bind-mounted into the deer-flow image.

## Global Constraints

- **Never** run `git merge`, `git rebase`, or `git diff upstream/main..HEAD`. The histories are unrelated; those commands report every file as changed and produce garbage.
- **Never** force-push `main`. Push to `fork/aipc1/v0.2.35-sync`.
- **Never** run `install.ps1` without first backing up `deploy/client-bundle/deer-flow-extensions-config.json`. Its render step regenerates that file from a **3-server stub** and silently deletes the **30** legal-database connectors.
- **Never** run `docker compose pull` (no service list). Pull **only** the `ghcr.io/jzkk720/*` services by name.
- **Never** delete a Docker volume. `pacgate-ai-bundle_pacgate-db-data` (230.2 MB, live), `qm-pacgate-coredata`, `qm-pacgate-pgdata` all hold real data.
- **Never** rename or move `deploy/client-bundle/`. `compose.prod.yaml` derives its project name from the directory.
- **Never** use `Get-Content`/`Set-Content` on UTF-8 Chinese files. Use `[System.IO.File]::ReadAllText`/`WriteAllText`.
- **Never** commit `OPERATOR.md`, `法律数据库MCP.md`, `境外法律数据库和网站.md`, or `百宸AI系统资源接入清单V2.docx`.
- Every patch file must stay **LF**. `.gitattributes` pins `*.patch`/`*.diff` to `-text`.
- A patch mount must go in **BOTH** `compose.bundle.yaml` and `compose.prod.yaml` — `test-workflow-compose-wiring.ps1` A5 asserts parity, and `install.ps1` uses `compose.prod.yaml`.
- Python is **not** on PATH. Use `C:\Program Files\Python313\python.exe`.
- `cargo` is **not** on the host PATH. Builds run in `rust:1.94-bookworm` with `export PATH=/usr/local/cargo/bin:/usr/local/bin:/usr/bin:/bin`.
- `docker exec pacgate-api` has **no** `curl` and **no** `python3`. Use `pacgate-mcp` (python3 + httpx) for API probes.
- Clear `HTTP_PROXY`/`HTTPS_PROXY` before any registry or HuggingFace call — they point at a dead `127.0.0.1:7890`.
- **Extract and merge files with `cmd /c "... > file"`, never with PowerShell `>` or `Set-Content -NoNewline`.** PowerShell `>` writes UTF-16LE; `Set-Content -NoNewline` collapses the file onto one line.

### The re-sanitize is mandatory, and it is the trap

The redactor verdict is computed at sanitize time and **stored**. A machine can
run 0.2.35 with a fully green stack and still have documents blocked by the old
rule. Measured now:

```
documents:  pending 220 | sanitized 49 | blocked 7
kb_chunks:  pending 5144 | sanitized 388 | blocked 67
```

Those 7 documents / 67 chunks need an explicit re-sanitize after the upgrade.

Two traps, both measured upstream:
- `/sanitize` **requires** `data_level`; omitting it returns `422 missing field data_level`, which reads like a broken endpoint but is validation.
- `/sanitize-rescan` is **read-only**. It reports `chunks_offending` and promotes nothing. `/sanitize` is what reopens a blocked document.

A verdict that stays `block` after re-sanitize has **rule** evidence
(checksum/pattern/context) left. That is supposed to block and needs a human —
do not retry it in a loop.

### qm / openviking changes in v0.2.35

- `compose.qm.yaml` adds `PORTAL_IDENTITY_SECRET` to `qm-pacgate-core`. Without it the chassis signs portal-identity tokens with `CORE_SIGNING_SECRET` (a different key from the one portal/web-ui/core verify with), so every identity it mints is silently rejected downstream.
- `setup-qm.ps1` fixes: a printed host it did not configure (`3a8c868`), a wrong host that broke every POST (`a17ca92`), a bare email written into `ADMIN_GRANTS` seeding zero admins (`07e5b0b`), and a sign-in URL the auth service refuses (`0bb863d`).
- `openviking` stays digest-pinned at `sha256:46f9e34cd372…` — **unchanged** by this release. Do not touch it.
- `test-qm-currentness.ps1` is new and expects qm staged at `deploy/client-bundle/qm-pacgate`. It is currently at `deploy/qm-pacgate`, so that gate reports `CANNOT CHECK (exit 2)` — not a failure.

- [ ] **Step 2: Write the re-sanitize probe**

```powershell
$py = @'
import httpx, os, sys
c = httpx.Client(base_url="http://pacgate-api:8080", timeout=900)
tok = c.post("/api/auth/login", json={"email": os.environ["PACGATE_API_EMAIL"],
             "password": os.environ["PACGATE_API_PASSWORD"]}).json()["token"]
h = {"Authorization": f"Bearer {tok}"}
ids = [l.strip() for l in sys.stdin if l.strip()]
for doc in ids:
    # data_level is REQUIRED. Omitting it returns 422 "missing field data_level",
    # which reads like a broken endpoint but is validation.
    r = c.post(f"/api/documents/{doc}/sanitize", headers=h, json={"data_level": "T3"})
    if r.status_code != 200:
        print(f"{doc} SANITIZE-FAILED {r.status_code} {r.text[:120]}")
        continue
    j = r.json()
    s = c.get(f"/api/documents/{doc}/sanitize-status", headers=h).json()
    print(f"{doc} verdict={j.get('verdict')} promoted={j.get('chunks_promoted')} "
          f"state={s.get('document_state')} incomplete={s.get('extraction_incomplete')}")
'@
$py | Out-File -Encoding utf8 "$env:TEMP\resan.py"
docker cp "$env:TEMP\resan.py" pacgate-mcp:/tmp/resan.py
```

  Tee-Object -FilePath runtime\upgrade-0.2.35\resanitize-log.txt
