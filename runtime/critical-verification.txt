  compose.prod.yaml        dir="client-bundle"  name: <none -> derived from dir>
  compose.bundle.yaml      dir="client-bundle"  name: pacgate-ai-bundle
  compose.qm.yaml          dir="qm-pacgate"  name: qm-pacgate

  => A file WITHOUT `name:` derives its project name from the directory,
     so moving/renaming that directory silently changes the project name.
