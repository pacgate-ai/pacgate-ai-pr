DECISIVE TEST: is the object PRESENT, or is it ABSENT from the backup?
==============================================================================

This distinguishes two very different claims:
  (a) the commit OBJECT is not in the bundle          -> data LOSS
  (b) the object IS in the bundle, but a fresh clone does not create a
      local REF pointing at it                        -> no loss at all

`rev-list --all` only walks LOCAL refs, so it answers neither on its own.
`git cat-file -e` asks about the object database directly. That is the
question that matters for a backup.
