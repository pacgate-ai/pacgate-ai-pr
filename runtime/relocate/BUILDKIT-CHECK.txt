BUILDKIT VALIDATION (docker build --check)
==============================================================================

`--check` validates the build graph WITHOUT executing it: it resolves the
base images, verifies COPY sources exist in the context, and reports lint
findings. Fast (seconds), no 30-minute Rust compile.

NOTE: --check still needs to resolve FROM images, so it requires network
      access to the registries. A failure to pull is NOT a build defect.
