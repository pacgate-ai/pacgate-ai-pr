=== 4. deer-flow source: where does the build expect it? ===

  The deer-flow-pacgate build uses context `.` = the PLATFORM root
  (pacgate-ai\). But the deer-flow source lives at pacgate-law\deer-flow,
  which is OUTSIDE that context. If the Dockerfile COPYs deer-flow/, the
  build cannot see it.

  --- COPY/ADD lines in deploy/deer-flow-pacgate/Dockerfile ---
    COPY pacgate-adapters/python/pacgate_deerflow_adapter /app/adapters/pacgate_deerflow_adapter
    COPY deploy/deer-flow-pacgate/config.yaml /app/backend/config.yaml

  pacgate-law\deer-flow exists        : True
  pacgate-ai\deer-flow exists        : False
  pacgate-ai\deploy\deer-flow-src    : False
